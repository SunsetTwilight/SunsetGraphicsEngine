# tests

自動テストを置く場所です。まだテストはありません。

予定しているテスト:

- **ヘッドレスの描画テスト**: ウィンドウなしで描画し、D3D12 のバリデーションメッセージが 0 件であることを確認します。
- **ABI のテスト**: バージョンや構造体サイズが一致しない DLL が拒否されることを確認します。
- **スキーマのテスト**: 記述子を JSON に書き出して読み戻し、元の値と一致することを確認します。

それまでは、サンプルを使った確認スクリプト [tools/check-sample.ps1](../tools/check-sample.ps1) を使ってください。
